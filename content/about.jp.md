こんにちは、アレックスと申します。現実世界の課題に対して、ユーザー中心の丁寧なソリューションを作ることを楽しんでいるソフトウェアエンジニアです。

主に.NET を使ったバックエンド開発と、React や React Native を使ったフロントエンド開発を専門としています。インフラ面では、Terraform、Ansible、Kubernetes を使ったプロジェクトにも取り組んできました。これらのプロジェクトはすべて GitHub でご覧いただけます。また、Python、Go、Vue.js を使った開発経験もあり、さまざまな技術スタックを試すのが好きです。

面白いことに取り組んでいる方や、プロフェッショナルなつながりを持ちたい方と、ぜひ交流できればと思っています。
